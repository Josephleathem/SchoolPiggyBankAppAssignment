# Week 2 - Hands On: Piggy Bank Children's App

---

## Learning Objectives Covered

**CO3** — Build an interactive Android user interface that collects and processes user input using various components, including Text, Spinner, and Button, while applying attributes, handling input methods, and performing basic arithmetic operations in code.

---

## Project Description

This project is a **Piggy Bank Children's App** — an Android application that allows children to:

- Enter the number of **quarters, dimes, nickels, and pennies** they have
- Select whether they want to **save** or **spend** the money using a Spinner component
- **Calculate** the total amount of money based on coin input
- **Display** the amount the child is saving or spending
- Navigate across **two screens**: a welcome screen and an input/output screen

---

## App Screens

### Screen 1 — Welcome Screen
- Displays a **title**
- Shows an **image**
- Contains a **button** that navigates the user to the second screen

### Screen 2 — Input/Output Screen
- Input fields for the number of **quarters, dimes, nickels, and pennies**
- A **Spinner** component to select between saving or spending
- Displays the **calculated result** showing how much the child is saving or spending
- A Calculate button to process input and show result

---

## Required Components & Attributes

- **Image** — displayed on the welcome screen
- **Spinner** — with a prompt and a string array for save/spend options
- **Hint attribute** — used on coin input fields
- **Custom layout** — original design required
